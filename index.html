Lo que se puede comprobar

Cada afirmación tiene un lugar donde mirarla. No hace falta creerme.

  • Cálculo de dinero con pruebas serias

    El cálculo de la deuda de cada socio tiene una especificación escrita, tests y mutation testing: se rompe el código a propósito y se mide cuántas roturas detectan los tests. Hoy detectan el 94,9 %.

    Ver el código

  • Contratos claros entre la API y las apps

    Cuando falta un precio, la API responde con un código estable y los datos para explicarlo, y cada app lo muestra a su manera. El contrato se escribió antes de programar.

    Leer el contrato

  • Pagos con Mercado Pago que se reconcilian

    Cada pago llega por webhook y, además, un trabajo concilia cada 30 minutos por si algún aviso se perdió.

    Ver cómo funciona

  • Cada club ve solo lo suyo

    Toda consulta filtra por el club. Un identificador válido de otro club no se puede leer, y esa regla está escrita y probada.

    Ver la regla

  • Calidad automática en cada cambio

    Cada pull request corre tests unitarios, tests de integración contra MongoDB real y una prueba del gateway.

    Ver el CI

  • Operación real, no una maqueta

    Todo corre en una Raspberry Pi con Docker, publicada por un túnel de Cloudflare y con HTTPS en un dominio propio.

    Ver la arquitectura

Un club por cada dato

Casi todo documento lleva el club al que pertenece y toda consulta filtra por él. Así el mismo sistema puede servir a varios clubes sin mezclar sus datos.

Permisos en un solo lugar

Cada acción tiene un permiso del tipo recurso:accion. Se verifica en un middleware, no a mano en cada pantalla, y cada club define sus roles.

Errores que dicen qué hacer

Si falta un precio, el sistema no falla: explica cuál cargar y avisa a quien puede hacerlo, con tiempo antes de que venza.

Registro de cambios

Las acciones importantes quedan en una auditoría que se consulta desde el panel.

Hosting propio y barato

Una Raspberry Pi alcanza para un club. La web de presentación está aparte, para que siga en pie aunque la Pi se caiga.

Si sos socio del CARC

La app te muestra cuánto debés y te deja pagar con Mercado Pago, guarda tu credencial con código QR, te avisa las novedades del club y registra tus visitas al muro y a las clases.
